# Cyberbullying Detection System
**Final Year Capstone Project | 2024–2025**

A full-stack application that classifies social media text as cyberbullying content using supervised machine learning, with a real-time social chat platform frontend for demonstration.

---

## Tech Stack

| Layer     | Technology                                |
|-----------|-------------------------------------------|
| ML Models | Scikit-learn — Logistic Regression, Random Forest |
| Vectorizer| TF-IDF (unigrams + bigrams, 5000 features)|
| Backend   | FastAPI + Uvicorn                         |
| Frontend  | HTML5, CSS3, Vanilla JavaScript           |

---

## Classification Categories

| Label               | Description                          |
|---------------------|--------------------------------------|
| `not_cyberbullying` | Neutral or positive social messages  |
| `hate_speech`       | Messages targeting groups or identity|
| `harassment`        | Direct personal attacks on individuals |
| `cyberbullying`     | Threats, manipulation, social exclusion |

## Setup & Run

### 1. Install Python dependencies
```bash
cd backend
pip install -r requirements.txt
```

### 2. Train the models
```bash
python train.py
```
This will:
- Load the 200-sample dataset (50 per class)
- Apply TF-IDF vectorisation
- Train both Logistic Regression and Random Forest
- Print accuracy and precision for each model
- Save `.pkl` files and `metrics.json` to `models/`

### 3. Start the API server
```bash
uvicorn app.main:app --reload --port 8000
```
API will be available at `http://localhost:8000`

### 4. Open the frontend
Open `frontend/index.html` directly in a browser.

## API Endpoints

| Method | Endpoint    | Description                                      |
|--------|-------------|--------------------------------------------------|
| GET    | `/health`   | Health check + model load status                 |
| POST   | `/predict`  | Classify text; body: `{text, model}`             |
| GET    | `/metrics`  | Accuracy and precision for both models           |
| GET    | `/models`   | List available models                            |

### Example request
```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "You are amazing, keep it up!", "model": "logistic_regression"}'
```

### Example response
```json
{
  "text": "You are amazing, keep it up!",
  "label": "not_cyberbullying",
  "label_display": "Not Cyberbullying",
  "confidence": 0.9421,
  "model_used": "logistic_regression",
  "is_cyberbullying": false,
  "probabilities": {
    "not_cyberbullying": 0.9421,
    "hate_speech": 0.0182,
    "harassment": 0.0241,
    "cyberbullying": 0.0156
  }
}
```

## Model Comparison

Both classifiers are evaluated on an 80/20 train/test split using:
- **Accuracy** — overall correct predictions
- **Weighted Precision** — precision weighted by class support

The training script prints a full `classification_report` for both models and identifies the best performer.

> For production use, replace the sample dataset with the
> [Kaggle Cyberbullying Classification Dataset](https://www.kaggle.com/datasets/andrewmvd/cyberbullying-classification)
> (~47,000 labelled tweets) for significantly higher accuracy.
